# Vector Explorer — Interactive Vector Physics Lab
**Marmara Koleji | Fen Lisesi**

Prepared by **Mehtap Aydoğan** · Hazırlayan: **Mehtap Aydoğan**

Bilingual (Türkçe / English) interactive vector simulation for high school physics: recognising vectors, scalar multiplication, head-to-tail and parallelogram addition, a teacher challenge builder, predict-test-explain activities and self-assessment.

## Run
Open `index.html` in a browser (no server, login or internet needed), or use the GitHub Pages link.

Teacher challenges are saved in browser storage and can be exported/imported as JSON or shared as a link.
